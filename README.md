## Descripción

TravelGo permite explorar diferentes destinos turísticos, consultar información sobre lugares de interés, conocer itinerarios de viaje y realizar una cotización según las características seleccionadas por el usuario.

### Funcionalidades principales

- Explorar destinos turísticos.
- Filtrar y buscar destinos.
- Consultar información detallada de cada destino.
- Buscar y filtrar itinerarios.
- Consultar itinerarios disponibles para cada destino.
- Seleccionar un itinerario para realizar una cotización.
- Personalizar una cotización según cantidad de viajeros y servicios adicionales.
- Enviar un formulario de contacto.

## Contenido

| Página | Descripción |
| --- | --- |
| Inicio | Presentación general de TravelGo, destinos e itinerarios recomendados. |
| Destinos | Búsqueda, filtrado y visualización de destinos turísticos. |
| Detalle del destino | Información y lugares destacados de cada destino. |
| Itinerarios | Búsqueda y filtrado de los itinerarios disponibles. |
| Cotización | Cálculo del precio de un viaje según itinerario, viajeros y servicios adicionales. |
| Sobre nosotros | Información sobre el proyecto y sus autores. |
| Contacto | Formulario para realizar una consulta. |
